Library metadata: the API a Rust producer embeds in its compiled library.

Each #[weaveffi::...] attribute describes the declaration it exports in a Frame and embeds the frame’s encoding in the producer’s library as an exported static named Frame::symbol (on wasm32, in the SECTION custom section instead). The CLI reads the frames back out of the built library, decodes them, keeps those with the crate’s own prefix, and assembles the Api it generates from. Because the frames are compiled with the code they describe, a declaration removed by #[cfg] is absent from both, and the generated bindings describe exactly what the library exports.

§Encoding

A frame is a little-endian u32 byte length followed by that many bytes of compact JSON (the Frame serialized with serde). Frames are self-delimiting, so a section holding several frames back to back decodes into all of them.

One frame describes one declaration: a free function, an interface (without its members), one interface member, a record, an enum, an error domain, or a callback interface. Each frame records the source location of its attribute, so assemble orders declarations by where they’re written (file, then line, then column), whatever order the linker laid the statics out in.

Functions§

assemble
Assemble the Api that the frames with prefix describe, ignoring every other frame (a dependency’s). Declarations of each kind are in source order. A frame repeated verbatim (a library that links an object twice) counts once.
decode
Decode every frame in bytes, which holds zero or more frames back to back (one static’s contents, or a whole wasm32 custom section).
frame_len
The byte length of the frame starting at bytes, length prefix included, read from its prefix alone.
frames
Every frame of api, as though one crate with prefix declared it in one file, in document order (for tests and tools that synthesize metadata).
is_symbol
Whether symbol names a metadata static: it ends in _META_ and 16 upper-case hex digits. A leading underscore (Mach-O’s symbol prefix) is fine; the frame’s own prefix decides whose it is.
symbol
The metadata symbol of the declaration path in the library with prefix (see Frame::symbol).
