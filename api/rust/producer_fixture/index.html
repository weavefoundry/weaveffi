A small producer exercising every kind of declaration the library metadata carries: an error domain with a payload, a type alias, a C-style enum, a record, a callback interface, and an interface whose members span two impl blocks. The Rust modules stock and receipt only organize the source: every declaration lands in the library’s one namespace. Declarations marked #[cfg(feature = "extra")] (an item, an impl block, and a module) exist only in a build with the extra feature, and so only in that build’s metadata.
