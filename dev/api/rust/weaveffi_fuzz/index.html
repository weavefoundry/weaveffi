Shared helpers for the WeaveFFI fuzz targets.

Fuzz targets live in the sibling *.rs files in this directory and are exposed as [[bin]] entries in Cargo.toml. They require the fuzzing feature (and a nightly toolchain with cargo-fuzz installed).

The value-buffer codecs are the runtime’s own (FfiType), keyed by the tag type export_runtime!() defines, which this crate defines once for every target and test.
