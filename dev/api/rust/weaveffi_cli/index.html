The library behind the weaveffi command-line tool: the Project that locates a project and loads its API (from an IDL, or from a Rust producer’s built library), the weaveffi.toml config, the language targets with their REGISTRY, the code-generation Orchestrator, and the package artifacts weaveffi package writes.

Every target renders from the validated Model alone, so symbol names and parameter lowering are computed once and shared.
