Expand description

The language targets: the Target trait every generator implements and the REGISTRY of every target the CLI drives.

A target owns its configuration (its [generators.<name>] table in weaveffi.toml), renders its files from the validated Model, and declares the few things the commands need to know about it through hooks: what weaveffi package builds from the per-platform libraries (package) and where weaveffi generate --dev puts the library (dev_bundle_dir, linkage). Nothing outside a target matches on its name.
