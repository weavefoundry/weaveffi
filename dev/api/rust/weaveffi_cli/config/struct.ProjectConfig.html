Struct ProjectConfig

pub struct ProjectConfig {
    pub project: ProjectTable,
    pub package: PackageTable,
    pub build: BuildTable,
    pub generators: BTreeMap<String, Table>,
    pub source: Option<Utf8PathBuf>,
}
Expand description

The whole weaveffi.toml: project paths, package identity, build settings, and per-target generator options.

Fields§

§project: ProjectTable

The [project] table.

§package: PackageTable

The [package] table.

§build: BuildTable

The [build] table.

§generators: BTreeMap<String, Table>

The [generators.<target>] tables, by target name. Each is checked against its target’s configuration when the file is loaded.

§source: Option<Utf8PathBuf>

Where the config was loaded from, when it came from a file.

impl ProjectConfig

Source

pub fn load(explicit: Option<&str>, input: &Utf8Path) -> Result<Self>

Load the project config: the file named by explicit when given, otherwise the nearest weaveffi.toml at or above the input file’s directory, otherwise the defaults.

§Errors

Returns an error when an explicitly named file cannot be read, or when any located file fails to parse.

Source

pub fn from_file(path: &Utf8Path) -> Result<Self>

Parse the config file at path.

§Errors

Returns an error when the file cannot be read or is not a valid weaveffi.toml.

Source

pub fn locate( explicit: Option<&str>, input: Option<&str>, ) -> Result<(Self, Utf8PathBuf)>

Resolve the project for a command: the config (explicit, discovered from input, or discovered from the current directory) and the input file (the argument, else [project] input).

§Errors

Returns an error when no input is given and no discovered config names one, or when a config file cannot be read or parsed.

Source

pub fn relative_to_config(&self, path: &Utf8Path) -> Utf8PathBuf

Resolve path against the directory holding the config file (or the current directory when there is no file).

Source

pub fn out_dir(&self, out: Option<&str>) -> Utf8PathBuf

The output directory: out if given on the command line, else [project] out, else bindings next to weaveffi.toml.

Source

pub fn dist_dir(&self, out: Option<&str>) -> Utf8PathBuf

The dist directory for weaveffi package: out if given on the command line, else [package] dist, else dist next to weaveffi.toml.

Source

pub fn targets(&self, filter: Option<&[String]>) -> Result<Vec<Box<dyn Target>>>

Build the targets named in filter (--target), else those listed in [project] targets, else every default target, in registry order, each with its [generators.<target>] configuration.

§Errors

Returns an error naming any entry that isn’t a registered target, so a typo fails instead of silently generating nothing, or when a target’s configuration doesn’t parse.
