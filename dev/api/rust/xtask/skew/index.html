cargo xtask skew: bindings against a library of a different version.

The contract (see the C ABI reference) lets a library grow: bindings generated from an older API load a newer library, a declaration the library changed is reported by its path, and one the library lacks fails to link (or, for a binding that loads the library at run time, to resolve). Each scenario here edits the calculator sample’s extracted API, generates the C target from the edited copy, and builds xtask/skew/check.c against the real calculator library.
