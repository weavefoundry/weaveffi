fn ttl_for( &self, key: &str, requested: Option<i64>, ) -> Result<Option<i64>, KvError>

The TTL a write of key gets, given the TTL the caller requested (absent for none): return it unchanged to keep it, another value to override it, or none to store without one. Consulted before admit.

Source

fn admit(&self, entry: &Entry) -> Result<Entry, KvError>

Admit an entry about to be stored, returning it as it should be stored. The policy may change its value, kind, TTL, tags, and metadata (its key and version are kept). Fail with Rejected to veto the write: put then fails with that same error.

Source

fn route(&self, key: &str, home: Arc<Store>) -> Result<Arc<Store>, ForeignError>

The store key belongs in: return home (the store put was called on) to keep it there, or another store to redirect it.
