Expand description

The C ABI’s type algebra (revision 6).

Every value crosses a call boundary as exactly one C value, whatever its position (parameter, return, async result, iterator item, or callback method parameter or return), chosen by its Family:

FamilyC type
Directthe scalar (int32_t, double, bool, …), or an enum’s {p}_{E} (typedef int32_t)
OptDirect{p}_opt_{prim}: { bool has; T value; } (an enum’s is {p}_opt_i32)
Run{p}_run: { const uint8_t* ptr; size_t len; }, len in bytes
Objectconst {p}_{I}* as a callable’s parameter (borrowed), else {p}_{I}* (one strong reference moves)

A callback-interface parameter is a {p}_{Cb} struct ({ void* ctx; const {p}_{Cb}_vtable* vtable; }) passed by value, and an iterator return is an opaque {p}_{Iter}*.

CType is prefix-agnostic; CType::render_c is the canonical spelling, and every other target maps it onto its own FFI vocabulary.
