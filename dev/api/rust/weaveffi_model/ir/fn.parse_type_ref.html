pub fn parse_type_ref(s: &str) -> Result<TypeRef, String>
Expand description

Parse the IDL’s compact type syntax into a TypeRef.

Handles primitive names (i32, string, bytes, and so on), iterators (iter<T>), lists ([T], with [u8] canonicalized to bytes), maps ({K:V}), and the optional suffix (T?). Any other identifier is taken to be a user-defined type name.

§Errors

Returns an error message when s is empty or only whitespace, or when a map type ({K:V}) is missing its : separator, including inside a nested type.
