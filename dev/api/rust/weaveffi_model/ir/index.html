weaveffi_model

Module ir 

Source
Expand description

In-memory intermediate representation: the data model a parsed WeaveFFI IDL document, or a Rust producer’s embedded metadata, becomes.

Api is the root. A library is one namespace: it declares records, enums, error domains, interfaces, callback interfaces, and free functions side by side, and every name is unique across the library. Types are referenced by TypeRef, which (de)serializes as a compact string (i32, [string], {string:i32}, Contact?, and so on).

The document model is unresolved: every user-defined type reference is a TypeRef::Named carrying the name exactly as written. Whether that name is a record, an enum, an interface, or a callback interface is decided by the validator, which lowers the document into the Model generators consume.

Package identity and per-generator options are not part of the IDL: they describe how bindings are shipped, not what the API is, and live in the weaveffi.toml project configuration instead.
