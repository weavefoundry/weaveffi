pub fn line_col_to_offset(src: &str, line: usize, col: usize) -> usize
Expand description

Convert a 1-indexed (line, col) pair into a 0-indexed byte offset within src. Returns 0 when either coordinate is 0 (i.e., unknown), and clamps to src.len() when the requested location is past the end.
