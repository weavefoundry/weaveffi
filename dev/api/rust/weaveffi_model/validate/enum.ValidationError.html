Expand description

Every way an Api can fail validation.

validate collects every variant it encounters. Each variant carries the names needed to render an actionable diagnostic, and the #[error]/#[diagnostic] attributes supply the message and help text shown to the user. The variant serializes as an object whose code is the variant name, with the variant’s fields alongside (the shape of weaveffi validate --format json failures).

DuplicateErrorCodeName

Two error codes share a name.

Several targets give each code a class or constant in the library’s namespace, so NotFound in two domains would collide there.

Fields

§name: String

The colliding code name.

§first: String

§second: String

SymbolCollision

Two declarations lower to the same C identifier.

Every C identifier is the library prefix plus a declaration’s name, so an async foo’s completion type {prefix}_foo_callback collides with a function named foo_callback, and a method Store.get with a function named Store_get.

Fields

§symbol: String

The colliding C identifier.

§first: String

The declaration that claimed the identifier first.

§second: String

The declaration that collided with it.
