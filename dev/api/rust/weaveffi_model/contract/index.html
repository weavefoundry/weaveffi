The contract: one fingerprint per declaration, which a generated binding checks against the library it loads before the first call.

Every declaration has an entry: each function, interface, interface member, record, enum, callback interface, callback method, error domain, and error code. An entry has:

  • an id, fnv1a64 of the declaration’s dotted path (open, Store.get, Listener.on_put, KvError.NotFound);
  • a hash, fnv1a64 of its canonical signature string.

A producer exports one function per entry, uint64_t {prefix}_contract_{id:016x}(void) (symbol), returning the hash. A binding resolves the function of every entry it was generated with and compares the hash: a missing function means the library lacks the declaration, and a different hash means it changed. Entries the library has and the binding doesn’t are fine, so adding a declaration (a function, a method, a record, an error code, or a callback method at the end of its interface) never breaks a deployed binding.

The canonical signature is computed from resolved types: aliases are substituted, [u8] is bytes, and each type is written in its IDL spelling by canonical (not by Display, so a cosmetic change to diagnostics can’t change a hash). Parameter and field names, docs, deprecation text, and error messages are excluded.

Sig builds these strings from parts, so the producer macro, which knows each type’s spelling only at compile time, assembles exactly the strings the CLI does.
