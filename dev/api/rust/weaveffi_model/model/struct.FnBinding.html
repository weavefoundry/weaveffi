Expand description

A callable (free function or interface member), fully lowered.

Fields§

§name: String

The callable’s name as written.

§doc: Option<String>

Documentation.

§deprecated: Option<String>

The deprecation message, if deprecated.

§kind: CallableKind

What kind of callable this is.

§owner: Option<String>

The interface a member belongs to, or None for a free function.

§path: String

The declaration path contract entries and diagnostics name (open, Store.get).

§params: Vec<ParamBinding>

The parameters (a method’s self is not one of them).

§ret: Option<RetTy>

The resolved return (None = void). A constructor’s is its interface.

§error: ErrorStrategy

How a reported error is interpreted.

§abi: AbiFn

The symbol to call, with its full slot list: the sync entry point, the async launcher, or the iterator launcher.

§shape: Shape

How the call completes.
