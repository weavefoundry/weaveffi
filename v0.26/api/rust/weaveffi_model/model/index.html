weaveffi_model

Module model 

Source
Expand description

The model: the one validated, fully lowered view of an API that every language backend consumes.

validate checks an Api and builds the Model exactly once per run. A library is one namespace, so the model is a flat list of declarations of each kind, and it owns everything a generator reads:

  • the library’s Identity (C symbol prefix, library name, package metadata) and the schema version;
  • every declaration with its types resolved (Ty, ParamTy, RetTy; no unresolved names) and its C symbols precomputed, so every backend agrees by construction;
  • every callable’s lowered AbiFn and Shape (sync, async, or iterator), and every callback method’s vtable entry;
  • the TypeIndex, which maps each type name to its declaration behind typed lookups such as Model::interface and Model::error_domain.

In ABI revision 6 every value crosses as one C value whose type is a pure function of the value’s type (CType::of), so a backend reads the idiomatic shape from the resolved types and marshals each value by its Family. Generators never see the Api.

ABI_VERSION
The C ABI revision this model lowers to. Producers export it from {prefix}_abi_version(), and every generated consumer checks it at load.
RESERVED_SYMBOL_FAMILIES
Identifier families the runtime surface and the generated C headers reserve, without the {prefix}_ that begins each: a declaration whose C symbol falls in one is a collision. contract_ holds the per-declaration contract functions, and the rest the fixed value-buffer helpers of {library}_buffer.h. (The optional-scalar structs and the value-buffer header’s composite codecs are exact names in Model::c_symbols.)
RUNTIME_SYMBOLS
The runtime symbols every producer exports (and every C header declares), without the {prefix}_ that begins each one.
VALUE_CODECS
The codec functions the C value-buffer helper header declares for each record, rich enum, and error payload struct T: T_write, T_read, T_decode, and T_free.
