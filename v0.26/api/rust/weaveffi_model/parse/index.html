Module parse 

Source
Expand description

Multi-format IDL parsing: turn YAML or JSON source text into an Api.

parse_api_str parses one document. load_api reads a document from disk with every file it imports, merged into one Api. On failure each returns a ParseError that carries the source text and, where available, a miette span, so the CLI can render a caret-annotated diagnostic at the offending line and column.
